# Asset Policy

`AUTHORITATIVE/` contains the only approved visual source for the standalone rebuild.

`REFERENCE/` contains historical composition references only. They may help with future Home integration and crop understanding, but they must not silently replace the approved base.

No asset in this package was newly generated for this handoff. The files are exact copies of existing project/user-provided material; the two legacy composition references were renamed from `.webp` to `.jpg` because binary inspection identifies them as JPEG data.

# Package Review — v1 to v2

The first handoff package was useful but incomplete for a careful Codex Luna Max takeover. This v2 corrects the following:

1. v1 contained an Arabic user checklist, so it was not fully English.
2. v1 did not include a formal asset/dimension contract.
3. v1 did not include the existing desktop/mobile composition references.
4. v1 used an approximate 640×427 geometry design space; v2 changes authority to native 960×640 or normalized coordinates.
5. v1 did not document that historical files named `.webp` are actually JPEG binaries.
6. v1 had only one execution prompt; v2 includes a full stage prompt library and recovery/review prompts.
7. v1 did not clearly separate authoritative source imagery from reference imagery.
8. v1 did not include explicit package preflight tooling for dimensions, hashes, English-only text, and constraints.
9. v1 did not provide a consolidated English integration map from the older Natural Eye planning documents.
10. v2 deliberately excludes old animation HTML implementations to reduce the risk of accidental code reuse.

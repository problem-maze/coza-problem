# Known Failures — Do Not Repeat

1. **Running code is not visible proof.** Past counters advanced while the user still perceived a static image.
2. **Subtle procedural motion can disappear at phone scale.** Use PROOF mode before realism tuning.
3. **Regular motion reads as synthetic.** Previous sine rhythms, uniform sparkles, and dashed waterfall motion looked manufactured.
4. **Patch stacking destroyed trust.** The user explicitly ordered a total rebuild. Do not recover old animation blocks.
5. **A stale state or CSS rule can silently kill behavior.** Search broadly before layering another override.
6. **Performance fixes must simplify, not silence.** A dead scene is not an optimized living scene.
7. **Lifecycle correctness and realism are separate.** A stable runtime can still look fake.
8. **Do not substitute a different source image.** Existing desktop/mobile references are historical composition references only.
9. **Do not author geometry in an approximate coordinate system.** Use native 960×640 or normalized coordinates.
10. **Do not optimize from screenshots alone.** Motion acceptance requires real-time phone evidence.

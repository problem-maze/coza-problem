# English-Only Package and Communication Contract

All documentation, prompts, comments, filenames, reports, test labels, and machine-readable metadata in this handoff package must be written in English.

The user may converse in Egyptian Arabic. User-facing status messages may be conversational Egyptian Arabic when useful, but implementation artifacts and package documentation should remain English unless the user explicitly requests otherwise.

When reporting progress:
- lead with the result,
- separate verified facts from interpretation,
- do not claim browser/phone verification that was not actually performed,
- avoid vague “should work” language when evidence is missing,
- state one next gate clearly.
